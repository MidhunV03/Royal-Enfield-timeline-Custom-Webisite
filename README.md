# 🏍️ Royal Enfield – Interactive History Website

An immersive, scroll-based website showcasing the rich history, legendary motorcycles, and engine evolution of **Royal Enfield**. Built using modern front-end technologies, the project combines smooth animations, interactive timelines, and premium visuals to create an engaging storytelling experience.

---

## About the Project

This website takes users through the journey of Royal Enfield, from its origins in **1901** to its modern lineup of motorcycles and engineering milestones.

The project focuses on creating a cinematic browsing experience using scroll-triggered animations, responsive layouts, and interactive components.

---

## Features

- Interactive Hero Section
- Scroll-based Royal Enfield History Timeline
- Engine Evolution Showcase
- Motorcycle Collection Carousel
- Embedded Videos
- GSAP Scroll Animations
- AOS Scroll Effects
- Fully Responsive Design
- Modern UI with Bootstrap 5
- Premium Dark Theme
